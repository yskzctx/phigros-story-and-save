# 电子书阅读说明

电子书无需 Root。下载 EPUB 后，用支持 EPUB 的手机或电脑阅读器打开。发行版仅提供 EPUB 本体。

本版对应 4.0.1（157），覆盖 15 个章节组、503 条收藏品记录、320 组全局条目系列。第九章共有 44 条记录，包含新增的 20 条。

建议先读“先认识这个世界”，再看主线、支线、人物和时间线。希望保留早期悬念时，可以先顺读主线，之后再看设定。全书含结局剧透。

正文段落下有“游戏内出处”。点击条目可以进入附录，查看完整的“收藏品 → 章节 → 条目名称”；附录还有返回正文引用位置的链接。游戏里可能显示“收藏品”或“收集品”，以对应章节和标题定位。

正文采用原创归纳和解读，并区分明确叙述、角色说法及综合解释。它不是整套游戏剧情原文，也不能代替游戏中的音乐、谱面演出和动画。

503 条覆盖范围来自本版客户端收藏品数据库。数据库之外的对话、历史网页谜题及后续更新可能包含额外信息；缺少证据的内容仍保留疑问。

版本来源及资源哈希见 [`verification/client-source.json`](../verification/client-source.json)。来源为公开分发镜像，客户端清单已核验版本和构建号；本书未经鸽游官方审校。
