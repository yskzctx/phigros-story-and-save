# 匿名全 AP 存档使用说明

适用版本：Phigros 4.0.1（157）。这是修改存档，满分成绩并非实际游玩所得，仅供离线体验与资料查看。

## 设备条件

仅安卓手机，且 BL（Bootloader）已经解锁、Root 权限已经取得。仅解锁 BL 而没有 Root 的设备不适用；iOS 不适用。这里的条件不针对电子书。

## 替换步骤

1. 在系统设置中强制停止 Phigros。
2. 使用具有 Root 权限的文件管理器，找到下方位置，将手机原文件另行备份。
3. 直接使用下载的 `com.PigeonGames.Phigros.v2.playerprefs.xml` 替换同名文件。
4. 保持原文件的所有者、用户组、访问权限；若替换改变了这些属性，按备份原属性恢复。
5. 建议断网首次启动，检查曲目、成绩、收藏品与剧情状态。
6. 若无法正常启动或内容异常，强制停止游戏，再恢复原存档及其属性。

```text
/data/data/com.PigeonGames.Phigros/shared_prefs/com.PigeonGames.Phigros.v2.playerprefs.xml
```

路径按分享者所用的安装环境提供；如手机不存在该目录，不要随意替换其他应用目录，先确认安装版本和游戏数据位置。

## 发行文件

发行版仅提供已加密的游戏存档 `com.PigeonGames.Phigros.v2.playerprefs.xml`，下载后按上述步骤替换，无需解压。
